# mfdma

A Python library for performing 1D and 2D multifractal analysis using the Detrended Moving Average (DMA) method.

## Features

- **MFDMA_1D**: Perform multifractal analysis on 1D time series data.
- **MFDMA_2D**: Conduct multifractal analysis on 2D data sets.
